# HTTP/3 Client Conformance Reconciliation

_The poseidon HTTP/3 client (http3/ + qpack/ + quic/, plus the client/ H3 transports) audited against the 666 client-relevant MUST/SHOULD-family obligations distilled in HTTP3_CLIENT_CHECKLIST.md from the verified RFC 9114 + 9204 + 9000 + 9001 + 9002 fact catalogs. Method: one judge per obligation cluster ruled each item PASS/FAIL/PARTIAL/NOT_APPLICABLE/UNTESTED with file:line evidence; every non-PASS was then re-checked by two independent default-refute verifiers on distinct lenses -- A hunts for implementing code or a test the judge missed, B challenges whether the obligation binds this client at all. Both overturn -> PASS; both confirm -> the gap stands; split -> REVIEW. 693 agents, 63.6M tokens._
