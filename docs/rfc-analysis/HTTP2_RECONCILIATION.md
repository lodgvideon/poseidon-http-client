# HTTP/2 Client Conformance Reconciliation

_The poseidon HTTP/2 client (`conn/` + `frame/` + `hpack/`, plus `client/` ALPN/push surface) audited against the **232 client-relevant MUST/SHOULD-family obligations** distilled in [HTTP2_CLIENT_CHECKLIST.md](HTTP2_CLIENT_CHECKLIST.md) from the verified RFC 9113 + RFC 7541 fact catalogs._

**Method.** One judge per obligation-cluster ruled each item PASS/FAIL/PARTIAL/NOT_APPLICABLE/UNTESTED with file:line evidence; every non-PASS was then re-checked by **two independent default-refute verifiers** instructed to overturn it to PASS. Both overturn → PASS; both confirm → the gap stands; split or a verifier lost to a session limit → REVIEW. 259 agents, 23.1M tokens. Verdicts below are the *synthesised* finals; the judge's own status is shown where it differs.

## Headline

| Verdict | Count |
|---------|-------|
| **PASS** | 166 |
| **FAIL** | 19 |
| **PARTIAL** | 19 |
| **UNTESTED** | 11 |
| **REVIEW** | 17 |
| **total** | 232 |

- **FAIL** — a MUST/MUST-NOT the code does not meet, confirmed by both verifiers. The cluster is *receiver-side robustness against a malformed/hostile server*: the client takes a lenient "drop the unexpected frame" posture where RFC 9113 requires a typed stream or connection error. Two are the opposite — **over-strict** — killing the whole pooled connection where the spec wants a single stream reset (an interop hazard, cf. the HTTP/1.1 `999` lesson).
- **PARTIAL** — met on the shipped default path but with an edge/opt-in gap (push-enabled path, caller-supplied config, un-materialised typed error code).
- **UNTESTED** — implemented correctly by construction, but no test pins it; cheap regression coverage to add.
- **REVIEW** — verifiers split, or one verifier was lost to a mid-run session limit (8 items); adjudicated by hand during the fix phase.

> The bulk of the FAILs are genuine conformance gaps for a *corporate-grade* client (Go's `x/net/http2` enforces essentially all of them). They are being closed in themed, test-first batches; see the fix tracker.
