# HTTP/2 Client Conformance Checklist

_Distilled from the verified fact catalogs (RFC 9113 + RFC 7541 HPACK). Client-relevant MUST/SHOULD-family obligations only; MAY/informative facts are excluded (advisory MAY list at end). Each row is judged in HTTP2_RECONCILIATION.md._
