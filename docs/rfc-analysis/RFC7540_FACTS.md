| `10-1` | informative | Server authoritativeness for a response is determined by the HTTP/1.1 authority rules: local name resolution for "http" URIs and authenticated TLS server identity for "https" URIs. <br>_(client,endpoint [CLIENT])_ | HTTP/2 relies on the HTTP/1.1 definition of authority for determining whether a server is authoritative in providing a given response | client/ — verify TLS transport authenticates server identity (ServerName/cert check) against the request :authority before treating responses as authoritative. |
